# Premier League positions, 2025/26

A single-page chart of league place after each matchweek. It opens on Brentford. The line stays on the latest three matchweeks, then zooms out across the whole season.

## Run

Open `index.html` in a browser. D3 is loaded from a CDN, so the page needs a network connection. There is no build step.

## Controls

- **Replay** runs the season again.
- **Change team** switches club. The line uses that club’s colours.

Place is the table at the end of each matchweek: points, then goal difference, then goals scored.
